Vendored rather than loaded at runtime, for the same reason as hls.js.

**Modification:** the ten icons this UI uses were extracted from the published
set and re-encoded as SVG path data in a JavaScript registry. No artwork was
redrawn, recoloured or otherwise altered; each path is byte-identical to the
source icon's `d` attribute. `web/icons.js` is generated by
`scripts/fetch-icons.mjs`, which records the exact source URL and can reproduce
the file.
